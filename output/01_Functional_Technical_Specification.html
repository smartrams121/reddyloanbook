Section 01Executive Summary

Daily Finance is a multi-tenant finance collection management platform designed for micro-lending and daily/weekly/monthly loan collection businesses operating primarily in Andhra Pradesh/Telangana, India. The platform enables business owners to manage customers, disburse loans, track collections, and generate comprehensive reports.

Key Capabilities

  • Multi-owner, multi-business
  • 4-tier RBAC
  • Loan lifecycle
  • Bulk operations
  • Financial reporting
  • Self-service registration
  • Password reset workflow
  • Cash book & expenses
  • Aadhaar SHA-256 hashing
  • Money in paise (integer)
  • IST timezone
  • Excel/PDF export

7.1 Authentication APIs

POST/api/auth/login
Authenticate user and create session.
Auth: Public (rate-limited: 5 attempts / 15 min)
{
  "username": "9553947222",
  "password": "MyPassword123!"
}

Returns 200 with auth-token HttpOnly cookie. Errors: 400 (validation), 401 (invalid), 429 (rate limited)

POST/api/auth/logout
Destroy session and clear cookie.
Auth: Optional
GET/api/auth/me
Get current authenticated user context (id, role, businessIds, villageIds).
Auth: Required (any role)
GET/api/auth/check-username?username=john123
Check if username is available for registration.
Auth: Public (rate-limited: 20/min)
POST/api/auth/register
Submit owner registration request with optional business details.
Auth: Public (rate-limited: 3/hour)
{
  "fullName": "Ravi Kumar", "phone": "9876543210",
  "username": "ravi_kumar", "password": "StrongPass1!",
  "confirmPassword": "StrongPass1!",
  "businessName": "Ravi Finance", "city": "Vizag",
  "villages": ["Pendurthi", "Gajuwaka"],
  "collectionType": "DAILY", "declaration": true
}
POST/api/auth/forgot-password
Submit password reset request by phone. Generic response prevents user enumeration.
Auth: Public (rate-limited: 3/hour)
POST/api/auth/change-password
Change password (forced change flow).
Auth: Required (any role)
GET/api/auth/profile
Get current user profile with businesses.
Auth: Required (any role)
PATCH/api/auth/profile
Multi-action: changePassword, updateProfile, archiveBusiness, updateBusiness.
Auth: Required (varies by action)

Generate report data (customers, loans, villages, employees, payments, payslips).

List employees or create employee (BUSINESS_ADMIN or AGENT).
POST/api/b/:businessId/upload
Upload file (photo max 5MB, document max 10MB).
